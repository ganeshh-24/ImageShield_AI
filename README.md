🛡️ Image Shield AI

AI-Powered Image Authenticity Detection and Digital Evidence Protection System

📌 About the Project

Image Shield AI is an AI-powered web application designed to analyze image authenticity and support digital evidence protection.

The system combines AI-based image classification, image analysis techniques, photo misuse scanning, risk assessment, and secure evidence storage in one platform.

✨ Key Features

- AI-Based Image Authenticity Detection
- Photo Misuse Scanner
- Image Metadata Extraction
- Face Detection
- Error Level Analysis (ELA)
- SHA-256 Evidence Integrity Verification
- Digital Evidence Locker
- Risk-Level Assessment
- PDF Evidence Report Generation
- SQLite Database Storage

🛠️ Technologies Used

- Python
- Flask
- PyTorch
- Hugging Face Transformers
- OpenCV
- Pillow
- ImageHash
- SQLite
- ReportLab
- HTML, CSS, JavaScript

⚙️ Main Modules

1. AI Image Detection
2. Image Analysis
3. Photo Misuse Scanning
4. Risk Assessment
5. Digital Evidence Management
6. PDF Report Generation

🎯 Project Objective

To develop an integrated platform that helps analyze image authenticity and organize digital evidence securely.

⚠️ Disclaimer

This project is an educational prototype. AI predictions and image similarity results are not definitive proof of authenticity or misuse. The Photo Misuse Scanner compares images with locally stored reference images and does not automatically retrieve images from external social media platforms.
